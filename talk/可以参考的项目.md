- MemGPT/Letta: stateful agents, 构建记忆的生命周期
- Pieces: 给开发者和 AI 工具用的长期工作记忆层，独立软件，可以暴露成MCP
- Mem0/OpenMemory: 基于 Mem0 的本地/开放记忆应用或 MCP server， 把“AI 记忆”从每个 agent 内部抽出来，变成一个共享、可携带、可本地部署的 MCP 服务；但记忆抽取和使用的质量，仍取决于 LLM/检索/规则系统的组合。
- Basic Memory: 是一个基于 Markdown 的开源 AI 长期记忆/知识库，通过 MCP 让 Claude、Cursor、Codex、ChatGPT 等工具共享同一套人类可读的长期上下文。
- A-MEM: 是一种受 Zettelkasten 卡片盒笔记法启发的 agentic memory 框架，它把 agent 记忆组织成可动态链接、可持续演化的结构化知识网络。非官方关联项目：https://github.com/DiaaAj/a-mem-mcp
- Zep/Graphiti: 带实体、关系、时间和来源的动态知识图谱，Graphiti 是 Zep 开源的实时 **temporal** knowledge graph 引擎。
- Voyager 谱系：智能体论文 “Voyager: An Open-Ended Embodied Agent with Large Language Models，只是架构。
- ACE论文: Agentic Context Engineering: Evolving Contexts for Self-Improving Language Models
